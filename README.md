# 🔊 Custom Hotkey Audio Mixer (AltMixer)

Легковесный, мультифункциональный и современный оверлей-микшер громкости для Windows 10/11 в стиле Fluent Design.

Создан специально для геймеров и стримеров: позволяет мгновенно открывать всплывающий микшер громкости в углу экрана нажатием **одной клавиши (Правый Alt или F8)**, а также регулировать звук музыки, Discord или игры прямо во время боя/дуэли комбинациями клавиш, не сворачивая окно игры!

## ✨ Основные возможности

* ⚡ **Мгновенный вызов:** Нажали **`Правый Alt`** (или **`F8`**) — микшер мгновенно появился в правом нижнем углу.
* 🛡️ **Защита от случайных срабатываний (Smart Tap):** Нажатия `Левого Alt` полностью игнорируются. Комбинации вроде `Alt+Tab` не открывают окно.
* 📐 **Изменяемый размер окна (Resizable):**
  * **Кнопки `➕` и `➖`** в заголовке — быстрое масштабирование окна.
  * **Ручка изменения размера `⤡`** в верхнем левом углу — свободное перетаскивание мыши.
  * Выбранный размер автоматически сохраняется в `config.json` и восстанавливается при следующем открытии.
* 🎯 **Clutch / Duck Mode (Приглушение музыки):** Нажатие `Right Alt + [` мгновенно сбрасывает громкость музыки до 12%, позволяя слышать тиммейтов в Discord и шаги в игре во время дуэлей. Повторное нажатие восстанавливает исходную громкость!
* 🎚️ **Глобальные хоткеи без открытия окна:** Регулируйте звук музыки, игры или Discord на лету прямо из полноэкранного режима.
* 🔢 **Быстрый Mute по цифрам:** Когда микшер открыт, клавиши **`1`**, **`2`**, **`3`**... мгновенно заглушают соответствующее приложение.
* 🎧 **Общая громкость системы:** Доступ к мастер-громкости ваших наушников/колонок.
* 🖱️ **Поддержка колесика мыши:** Наведите курсор на любой ползунок и крутите колесо мыши для плавной регулировки.
* 🎨 **Windows 11 Fluent UI:** Темная тема, скругленные углы (DWM + transparent overlay).
* 🔔 **Системный трей:** Программа тихо висит в трее у часов.
* 🚀 **Безопасная автозагрузка:** Включается через официальный ярлык в папке `Startup` (без правок реестра, 100% дружит с Bitdefender и другими антивирусами).

## ⌨️ Горячие клавиши (Hotkeys)

### 1. Управление микшером
| Комбинация | Действие |
| :--- | :--- |
| **`Правый Alt`** (одиночный тап) | Открыть / Скрыть микшер |
| **`F8`** | Альтернативная клавиша открытия / закрытия |
| **`Esc`** | Закрыть микшер |
| **`1` .. `9`** (при открытом микшере) | Мгновенный Mute приложения № 1..9 |
| **`➕` / `➖`** в заголовке | Увеличить / Уменьшить размер окна |
| **Перетаскивание `⤡`** | Свободное изменение размера окна мышью |

### 2. Музыка (Spotify, Яндекс Музыка, Firefox, Chrome и др.)
| Комбинация | Действие |
| :--- | :--- |
| **`Правый Alt + M`** | Mute / Unmute музыки |
| **`Правый Alt + Стрелка Вниз`** | Сделать музыку тише на 10% |
| **`Правый Alt + Стрелка Вверх`** | Сделать музыку громче на 10% |
| **`Правый Alt + [`** (или **`Х`**) | **Clutch Mode:** приглушить музыку до 12% (или вернуть обратно) |

### 3. Игра (Minecraft / Fabric / другие игры)
| Комбинация | Действие |
| :--- | :--- |
| **`Правый Alt + G`** | Mute / Unmute звука игры |
| **`Правый Alt + Page Down`** | Сделать игру тише на 10% |
| **`Правый Alt + Page Up`** | Сделать игру громче на 10% |

### 4. Discord и Общий звук
| Комбинация | Действие |
| :--- | :--- |
| **`Правый Alt + D`** | Mute / Unmute звука Discord |
| **`Правый Alt + -`** | Сделать Discord тише на 10% |
| **`Правый Alt + =`** | Сделать Discord громче на 10% |
| **`Правый Alt + Backspace`** | Mute / Unmute всей системы (Master Volume) |

## ⚙️ Настройка через `config.json`
В файле `config.json` в папке программы можно добавлять свои процессы в списки:
```json
{
    "window": {
        "width": 420,
        "height": 530
    },
    "music_apps": [
        "spotify.exe", "firefox.exe", "chrome.exe", "yandexmusic.exe"
    ],
    "game_apps": [
        "millidaminecraft.exe", "minecraft.exe", "javaw.exe"
    ],
    "discord_apps": [
        "discord.exe", "discordcanary.exe"
    ]
}
```

## 🚀 Установка и запуск

### 1. Требования
* Windows 10 или Windows 11
* Установленный [Python 3.10+](https://www.python.org/)

### 2. Установка зависимостей
```bash
git clone https://github.com/BoxingHarmoni/custom-hotkey-audio-mixer.git
cd custom-hotkey-audio-mixer
pip install -r requirements.txt
```

### 3. Запуск
Дважды кликните по `Запустить_микшер.bat` (или `start.bat`), либо выполните:
```bash
pythonw app.pyw
```
