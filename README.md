# 🔊 Custom Hotkey Audio Mixer (AltMixer)

Легковесный и современный оверлей-микшер громкости для Windows 10/11 в стиле Fluent Design.

Позволяет мгновенно открывать всплывающий микшер громкости в углу экрана нажатием **одной клавиши (Правый Alt или F8)**, чтобы быстро отрегулировать звук отдельного приложения (Discord, игра, музыка, браузер), не сворачивая игру и не переключая окна.

## ✨ Основные возможности

* ⚡ **Мгновенный вызов:** Нажали **`Правый Alt`** (или **`F8`**) — микшер мгновенно появился в правом нижнем углу.
* 🛡️ **Защита от случайных срабатываний (Smart Tap):** Если вы используете `Правый Alt` в комбинациях с другими клавишами (`Alt + Tab`, `Alt + F5` и т.д.), микшер **не открывается**. Он реагирует только на чистое одиночное нажатие.
* 🎚️ **Управление по приложениям:** Отдельные ползунки и кнопки заглушения звука (`Mute`) для каждого активного процесса (Minecraft, Discord, Spotify, Firefox, Telegram и т.д.).
* 🎧 **Общая громкость системы:** Быстрый доступ к мастер-громкости ваших наушников / колонок.
* 🖱️ **Поддержка колесика мыши:** Наведите курсор на любой ползунок и крутите колесо мыши для быстрой регулировки звука.
* 🎨 **Windows 11 Fluent UI:** Темная тема, стильные акценты, плавные скругленные углы.
* 🔔 **Системный трей:** Программа тихо висит в трее у часов и не отвлекает.
* 🚀 **Официальная автозагрузка:** Включается через стандартный ярлык в папке `Startup` (без сомнительных правок реестра, которые не любят антивирусы вроде Bitdefender).
* 🔒 **100% безопасность для антивирусов:** Работает через подписанный интерпретатор `pythonw.exe`, не вызывая ложных срабатываний.

## ⌨️ Управление

| Действие | Горячая клавиша |
| :--- | :--- |
| **Открыть / Скрыть микшер** | `Правый Alt` (одиночный тап) или `F8` |
| **Закрыть микшер** | `Esc`, повторный тап `Правый Alt` / `F8` или крестик `✕` |
| **Регулировка звука** | Перетаскивание ползунка или **колесико мыши** над ним |
| **Быстрый Mute** | Клик по кнопке динамика `🔊` / `🔇` рядом с приложением |

## 🚀 Установка и запуск

### 1. Требования
* Windows 10 или Windows 11
* Установленный [Python 3.10+](https://www.python.org/)

### 2. Установка зависимостей
Склонируйте репозиторий и установите библиотеки:
```bash
git clone https://github.com/BoxingHarmoni/custom-hotkey-audio-mixer.git
cd custom-hotkey-audio-mixer
pip install -r requirements.txt
```

### 3. Запуск
Запустите файл `app.pyw` (или дважды кликните по `Запустить_микшер.bat`):
```bash
pythonw app.pyw
```
Программа запустится в фоновом режиме и появится в трее у часов.

## ⚙️ Автозагрузка вместе с Windows
Чтобы микшер запускался автоматически при старте системы:
1. Нажмите правой кнопкой мыши по иконке в трее (у часов).
2. Поставьте галочку **«⚙️ Запуск с Windows»**.
